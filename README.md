# 麦当劳 Wrapped（mcd-wrapped）🎉

一个基于**麦当劳 MCP** 的 Skill：一句话给用户生成一份 Spotify Wrapped 风格的**麦当劳年度消费报告**——总花费、客单价、0 元核销单、最常点商品、招牌组合、时段/门店/城市画像、年度「麦门人格」认证，外加基于真实优惠的个性化点单建议。

## ✨ 亮点

| 维度 | 本项目的设计 |
| --- | --- |
| 实用性 / 创新性 | 把冰冷的订单流水变成可分享的年度报告；「站外团购补录」「双本账」「麦门人格认证」是纯增量洞察，订单列表里看不到 |
| Agent 协作水平 | 工作流六步固定（拉数→甄别补录→清洗→算指标→判人格→出报告）；人格判定表让输出确定可复现；建议环节可主动调用 `available-coupons` 把建议落到真实优惠 |
| 工作流完整度 | 覆盖空账号、接口报错、字段缺失、已取消订单、补录文件损坏等边界；模板行块化，数据多少都能出报告 |
| 可复现性 | 数据契约来自 `order-list` 实测（含 `realTotalAmount` 单位为元、套餐子项字段名为 `name` 等实测坑位）；指标口径有明确定义公式 |
| 创意表达 | Wrapped 式深色金红视觉、人格认证徽章、基于真实数据的「判词」文案 |

## 🧩 MCP 集成

使用麦当劳中国官方远程托管的 MCP Server（`https://mcp.mcd.cn`），核心工具为 `order-list`，辅以优惠券/活动日历工具。详见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。

## 🍟 使用方式

安装 skill 后对 Agent 说：

- 「生成我的麦当劳年度报告」
- 「我今年在麦当劳花了多少钱？」
- 「给我整一个麦门 wrapped」

Agent 会自动调用 `order-list`，几十秒后给你一份可在浏览器直接打开的 HTML 报告（`demo/mcd-wrapped-2026.html` 为真实账号数据生成的演示），方便截图分享。

**站外团购补录**：0 元核销单很可能是抖音/美团团购券（钱花在站外），Agent 会在报告前主动询问；也可随时补记——

- 「我在抖音买了个 25 块的双人套餐券，昨天用的，记一下」
- 「那单 0 元的其实是团购券，29.9 买的」
- 「那一单里堡是团购券 25.8，薯条是 App 内买的」——支持**单品级补录**：一单里部分商品用站外券（混合单）也能分开记账

记录存在本地 `mcd-wrapped-records.json`，报告会把"应用内消费 + 站外实付"合成真实总花费，并区分「团购核销单」「混合单」和真正的 0 元薅羊毛单。

## 👥 目标用户

- 想回顾全年麦当劳消费、生成可分享年报的普通消费者
- 精打细算、常买站外团购券的"团购精算师"
- 喜欢人格测试 / Wrapped 类内容、愿意晒图的社交分享型用户

## 🔧 安装

前置条件：已配置麦当劳 MCP（`https://mcp.mcd.cn` + 个人 Token，申请方式见[官方使用指南](https://github.com/M-China/mcd-mcp-server)），并已登录产生过订单。

把本仓库的 skill 文件（`SKILL.md` + `assets/`）放到你的 Agent 技能目录，例如：

- 项目级：`<项目>/.agents/skills/mcd-wrapped/`
- 用户级：`~/.agents/skills/mcd-wrapped/`

## 🔒 隐私

- 报告只聚合统计指标，**不输出**订单号、手机号、地址；演示报告已做城市级脱敏。
- 数据仅来自用户本人账号的 `order-list` 返回与用户自填的补录记录，报告不外发，保存和分享均由用户自己完成。
